# CS50P – Introduction to Programming with Python 🐍

This repository contains my solutions and projects from **CS50P: Introduction to Programming with Python** by Harvard University.

I created this repository to keep track of my progress as I learned Python and to have a place where I can look back at the problems I worked through, the mistakes I made, and the concepts I gradually became more comfortable with.

At the beginning, a lot of Python concepts were new to me. As I worked through the problem sets, I became more comfortable with writing functions, working with data, handling errors, testing my code, and thinking through problems step by step.

## 📚 What I Learned

Throughout CS50P, I worked with topics such as:

* Functions and Variables
* Conditionals
* Loops
* Exceptions
* Libraries
* Unit Testing
* File I/O
* Regular Expressions
* Object-Oriented Programming
* Third-Party Libraries
* Command-Line Arguments
* Type Hints
* Documentation and Code Organization
